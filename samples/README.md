# Samples

The archive and the texture the tests read, copied from
[zenkit-rs](https://github.com/Zira3l137/zenkit-rs/tree/main/samples), which has them from
[ZenKit](https://github.com/GothicKit/ZenKit)'s test samples (MIT). `basic.vdf` holds a few text
files in folders; `erz.tex` is a DXT1 texture of the game's.
